# 新浪行情接口（`hq.sinajs.cn`）代码前缀与字段速查

`tools/push_auto.py` 取行情用的就是这个接口。这份文档记录**实测**得到的前缀、字段布局与坑，
供以后加标的时先查这里、再用文末的脚本复核。

> 本文所有「实测」标记的数据都是 2026-09-29 用标准库 urllib 直接打 `hq.sinajs.cn` 抓的
> 原始响应，来源见每节的响应片段。凡是**没有**实测过的，明确写了「未实测」，不要当结论用。

---

## 1. 端点与三个必需条件

```
https://hq.sinajs.cn/list=<代码1>,<代码2>,...
```

| 条件 | 值 | 不满足的后果 |
|---|---|---|
| `Referer` | `https://finance.sina.com.cn` | **HTTP 403** |
| `Accept` | `*/*` | 部分环境下被拒 |
| `User-Agent` | 常规浏览器 UA | 可能被拒 |
| 响应编码 | **GBK / gb18030**（不是 UTF-8） | 中文名乱码 |

响应是一行一条，形如：

```
var hq_str_<key>="<逗号分隔字段>";
```

`<key>` 就是请求里的代码（`s_` 简版请求则是 `s_<code>`）。**行序 = 请求序**。

> `rn=<随机数>` 破缓存是社区常见做法（easyquotation / akshare / tushare 都加）。**我们没加**：
> 实测同一个 URL 每 20s 连打 5 次、跨过连续竞价开盘时刻，5 次里有 3 组取值不同 → 中间 CDN
> 没有缓存我们的轮询 URL。`--stock-dry-run` 可自行复验。

## 2. 前缀总表（全部实测）

| 前缀 | 是什么 | 完整版字段数 | 有 `s_` 简版？ | 涨跌幅来源 | 参与日期投票 |
|---|---|---|---|---|---|
| `sh` | 沪市 A 股 / 沪市指数 / 沪市 ETF / 沪市 B 股 | **34** | ✅ | 自算 `(f[3]−f[2])/f[2]` | ✅ |
| `sz` | 深市 A 股 / 深市指数 / 深市 ETF / 深市 B 股 | **33** | ✅ | 自算 `(f[3]−f[2])/f[2]` | ✅ |
| `bj` | 北交所 | **33 或 39**（不固定！） | ❌ `s_bj430047` 空串 | 自算 | ✅ |
| `int_` | 海外指数（`int_nikkei` / `int_dji` / `int_nasdaq` / `int_sp500` / `int_hangseng` / `int_ftse`） | **4** | ❌ | **`f[3]` 直给** | ❌ |
| `hf_` | 外盘期货（`hf_NQ` / `hf_ES` / `hf_YM` / `hf_CL` / `hf_HSI` / `hf_CHA50CFD` / `hf_XAU`） | **15**（`hf_XAU` 14） | ❌ | **自算 `(f[0]−f[7])/f[7]`** | ❌ |
| `hk*` | 港股（`hkHSI` / `hk00700` / `hk09988` / `hkHSCEI`） | **19** | ❌ | **`f[8]` 直给** | ❌ |
| `rt_*` | 延时行情（`rt_hkHSI`） | 25 | — | 位置同 `hk*`，**语义是延时** | — |
| `nf_*` | 国内期货连续（`nf_IF0` / `nf_AU0` / `nf_RB0`） | 44~50 | ❌ | **布局完全不同，未支持** | — |
| `s_` | 简版修饰符，加在**上面**的代码前面 | 见下 | — | `f[3]` 直给 | ❌（无日期） |

**无效代码一律返回空串而不是 404**，所以「请求成功」不等于「代码有效」：
```
s_sh999999    → var hq_str_s_sh999999="";
sh932000      → 空串   （中证2000，没有交易所挂牌代码，新浪不供）
sh899050      → 空串
sz000300      → 空串
hsi / hk_hsi  → 空串   （大小写错，见 §4）
```

## 3. 五种已支持形态的逐下标布局

### 3.1 `s_` 简版 —— 6 字段
```
var hq_str_s_sh000300="沪深300,4332.9418,-7.8132,-0.18,748503,850000000";
                     [0]名称 [1]点位 [2]涨跌额 [3]涨跌幅% [4]成交量 [5]成交额
```
- **`f[3]` 就是涨跌幅百分比，不用自己除。** 算术自校验：`(4332.9418−4340.7550)/4340.7550×100 = −0.18` ✅
- **没有日期字段**
- 对个股（`s_sh600519`）、ETF（`s_sh510300`）、指数都一样有效
- **`f[1]` 点位为 0 是合法值**：开盘前深市指数（`s_sz399006` 创业板指 / `s_sz399303` 国证2000 / `s_sz399001` 深证成指）返回 `点位=0.00, 涨跌幅=0.00, 成交量=0`，而同时沪市 `s_sh000300` 有真实点位。**拿「点位 <= 0」当无效行会把深市指数整行丢掉** —— 这是本项目修过的一个真 bug。

### 3.2 A 股 / 北交所完整版 —— 34（沪）/ 33（深）字段
```
var hq_str_sh000300="沪深300,0.0000,4340.7550,4332.9418,...,2026-09-29,10:26:01,00,";
var hq_str_sz399006="创业板指,0.0000,3139.825,3138.700,...,2026-09-29,09:05:12,00";
```
```
[0]名称  [1]今开  [2]昨收  [3]现价/最新点位  [4]涨跌额  [5]涨跌幅%
[6]买价  [7]卖价  [8]成交量  [9]成交额 … [30]日期  [31]时间  [32]状态位
[33] 沪市独有的尾部空字段（深市没有，故 34 vs 33）
```
- **指数和个股是同一套布局**，`(f[3]−f[2])/f[2]` 对两者都成立。⚠️ 别用「字段少的是指数」判形态 —— 指数完整版也是 33/34 字段；那个说法只在 `s_` 简版下成立。
- `f[30]` 日期、`f[31]` 时间，**sh / sz 位置一致**（实测）；沪 `f[33]` 是空串，**没有稳定契约，不要去读**
- **北交所 `bj` 字段数不固定**：`bj430047`/`bj872925` 是 33，`bj920445` 是 39（尾部多出真实数据）。也别按字段数判形态。
- **存在「格式完整但日期陈旧」的响应**：实测 `bj872925`（停牌）返回 `f[30]=2026-09-22`、7 天前，`f[2]=f[3]=0.000`，不是空串。所以日期兜底要**多标的投票取最新**（见 §6）。
- 完整版要保留 `现价 > 0` 守卫：盘前深市指数完整版 `f[3]=0.000`，不守卫会算出 **−100%**。
  副作用（实测、且是想要的）：停牌/长期无成交的代码全字段为 0（如 `bj430047` 返回 33 字段但 `f[2]=f[3]=0.000`）会被**整行跳过**，日志是「跳过 bj430047：昨收或现价无效」。注意这与简版不同 —— 简版的 0 点位要放过（§3.1），完整版的 0 现价要拦（否则 −100%）。

### 3.3 `int_` 海外指数 —— 4 字段
```
var hq_str_int_nikkei="日经指数,44946.64,-408.35,-0.90";
                        [0]名称 [1]现价 [2]涨跌额 [3]涨跌幅%
```
- **`f[3]` 直给涨跌幅**，别套 A 股完整版的 `(f[3]−f[2])/f[2]` —— 那里 `f[2]` 是昨收、这里是**涨跌额**，套上去会把日经 `-0.90%` 算成 `+0.02%` 这种**看着还挺像样**的垃圾。
- 涨跌幅小数位不统一：日经 `-0.90`（2 位）、恒生 `-0.600`（3 位）→ 统一 `round_change()` 归一到 2 位
- 没有日期字段

### 3.4 `hf_` 外盘期货 —— 15 字段（`hf_XAU` 14）
```
var hq_str_hf_NQ="30477.025,,30516.500,30517.750,30616.000,30430.000,10:26:53,
                  30566.250,30560.500,0,1,1,2026-09-29,纳斯达克指数期货,0";
```
```
[0]现价  [1]（hf_NQ 空 / hf_XAU 有值，语义不稳，别用）  [2]买价  [3]卖价
[4]最高  [5]最低  [6]时间 HH:MM:SS  [7]昨收  [8]开盘  [9]持仓  [10] ?  [11] ?
[12]日期  [13]中文名  [14]'0'（hf_XAU 没有这一位，故 15 vs 14）
```
- **没有现成涨跌幅**，必须自算 `(f[0]−f[7])/f[7]*100`（要求 `f[7] > 0`）。实测 `hf_NQ` 30477.025/30566.250 → `−0.29%`
- 名称取 `f[13]`（中文，只进日志，不上屏）
- `f[12]` **有**日期，但**故意不参与日期投票**（§6）
- 别按字段数判形态（`hf_XAU` 少一位）

### 3.5 `hk*` 港股 —— 19 字段
```
var hq_str_hkHSI="HSI,恒生指数,24648.640,24642.510,24648.640,24479.610,24507.299,
                  -135.211,-0.549,0.00000,0.00000,53762078,3320140923,0.000,0.000,
                  28056.100,22518.000,2026/09/29,10:23";
```
```
[0]英文名(ASCII: HSI/TENCENT/BABA-W)  [1]中文名  [2]今开  [3]昨收  [4]最高  [5]最低
[6]现价  [7]涨跌额  [8]涨跌幅%  [9]买价  [10]卖价  [11]成交量  [12]成交额
[13]/[14] 0.000  [15]52周最高  [16]52周最低  [17]日期 2026/09/29  [18]时间
```
- **`f[8]` 直给涨跌幅，不自算**。算术自校验：`(24507.299−24642.510)/24642.510 = −0.5487%` 与 `f[8]=−0.549` 吻合。与 `hf_` 正好相反。
- 有效性只认 `f[0]` 非空 + `f[8]` 可解析成有限数；**不拿现价 `f[6] <= 0` 当门槛**（同 §3.1 的盘前 0 原则）
- `f[17]` 日期是**斜杠格式**，与 A 股的 `2026-09-29` 混进同一个字符串 `max()` 会比错

## 4. 大小写：非对称规则，别「顺手统一」

实测（新浪**对所有代码**都大小写敏感）：

| 写法 | 结果 |
|---|---|
| `sh000300` | ✅ 34 字段 |
| `SH000300` | ❌ 空串 |
| `Sz399006` | ❌ 空串 |
| `s_Sh000300` | ❌ 空串 |
| `hf_NQ` | ✅ 15 字段 |
| `hf_nq` | ❌ 空串 |
| `hkHSI` | ✅ 19 字段 |
| `hsi` / `hk_hsi` | ❌ 空串 |
| `int_nikkei` | ✅ 4 字段（本来就是全小写） |

**规则**（`normalize_symbol()`）：

| 代码形态 | 处理 |
|---|---|
| `^(sh\|sz\|bj)\d{6}$`（大小写不敏感判定） | **转小写**（`SH000300` → `sh000300`） |
| 其余（`hf_*` / `hk*` / `int_*` / `nf_*`） | **原样保大小写** |
| 前导 `s_` | 大小写不敏感地剥掉 |

因为 `int_nikkei` 全小写、`hf_NQ` / `hkHSI` 必须大写，这条规则天生不对称 —— **代码里必须留注释**，
否则以后有人「统一成一种」就会把 `hf_NQ` 打死（症状：整拍 `未解析到有效行情` + 6 行重试噪音）。

## 5. 其它已实测的坑

| 坑 | 表现 |
|---|---|
| 无效代码返回 200 + 空串 | 不报错，静默少一行；「请求成功」≠「代码有效」 |
| 盘前深市指数点位 0 | 简版与完整版都是 0；拿它当无效行会丢行/算出 −100% |
| `hf_` 字段数 14 或 15 | 按字段数判形态会崩 |
| `bj` 字段数 33 或 39 | 同上 |
| `rt_` 25 字段但位置同 `hk*` | 靠字段数挡不住，只能靠**前缀名单**拦，否则静默拿延时价当实时价 |
| 陈旧但结构完整的日期 | `bj872925` 报 7 天前的日期 → 只信一个标的会把交易日误判成休市 |
| `nf_` 布局完全不同 | `nf_IF0` 50 字段、`f[30]='0.000'`（**不是日期**）→ 别对任何前缀盲取 `f[30]` |

## 6. 日期投票只用 A 股

`sina` 完整版的 `f[30]` 是行情日期，用来判「今天是不是交易日」（节假日兜底）：
**日期不等于今天 → 判休市**。

`SinaQuotes` 的做法：

1. 每拍请求里让**每个 A 股代码**都同时捎带一份完整版（`list=s_sh000300,sh000300` 两行都返回，所以一次请求就够）
2. **取所有完整版日期里最新的一天**（`max()`）：
   - 停牌标的的陈旧日期被更新的日期盖掉 → 不会把交易日误判成休市
   - 节假日时全员报同一个上一交易日 → `max` 仍是那天 → 正确判休市（`max` 不会掩盖真正的休市）
3. **`int_` / `hf_` / `hk*` 三种非 A 股形态一律 `date=""` 不参与投票**，两条理由：
   - 交易日历不同（外盘/港股各有各的假期），混判会把节假日或非交易日误判成开市
   - `hk*` 的日期是斜杠格式，混进同一个 `max()` 会按字符串序比错
   - 后果：纯 `int_` / `hf_` / `hk*` 列表 `data_date` 为 `None`（`--stock-dry-run` 显示「行情日期 (取不到)」）

另有两条与日期投票配套的本地时间策略（`--market-open/--market-close`，默认 09:20~15:30 半开区间），
见 `push_auto.py` 顶部 docstring 与 `AGENTS.md`。

## 7. 代码段规律（哪些是指数）

新浪没有「指数清单接口」，代码得自己点。可用的判据：

- **`sh000xxx`** → 沪市/中证在沪挂牌的**指数**（000300 沪深300、000905 中证500、000688 科创50、000016 上证50、000852 中证1000）
- **`sz399xxx`** → 深市/深证信息**指数**（399001 深证成指、399006 创业板指、399303 国证2000、399673 创业板50）
- 沪市 ETF/基金是 `5xxxxx`（`sh510300` 沪深300ETF、**首位是 5 不是 6**）
- 沪市 A 股是 `6xxxxx`（`sh600519` 茅台、688 科创板）
- B 股：`sh900xxx`、`sz200xxx`
- **同一个数字在不同市场含义不同**：`sh000001` 是上证指数，`sz000001` 是平安银行

⚠️ 常见错误规律（实测反例）：「`6` 开头 = 基金」❌（`sh600519` 是股票）；「`9` 开头 = 指数」❌（`sh900901` 是云赛 B 股）；「非交易所挂牌指数（`sh932000` 中证2000）新浪能取」❌（空串）。

**要「只推指数」最稳的是白名单**（本项目就是这么用的），别靠代码段规律外推。

## 8. 我们代码里的对应位置

| 概念 | 位置 |
|---|---|
| 前缀常量 | `A_SHARE_PREFIXES`（只管转小写）/ `SIMPLE_PREFIXES`（管简版，`sh`/`sz`）/ `NOSIMPLE_PREFIXES`（`int_`/`hf_`/`hk`）/ `UNSUPPORTED_PREFIXES`（`rt`） |
| 大小写归一 | `normalize_symbol()` |
| 形态分流 | `SinaQuotes._parse_quote()` |
| 简版优先 / 完整版只贡献日期 | `SinaQuotes._parse()` |
| URL 构造（混用） | `SinaQuotes.build_url()` |
| 形态回归用例 | `python3 tools/push_auto.py --self-test`（66 条，含每种形态与每个坑） |

**注意 `A_SHARE_PREFIXES` 与 `SIMPLE_PREFIXES` 不是一回事**：`bj` 要转小写但**没有** `s_` 简版。
合成一个常量会让 `BJ430047` 静默取不到数据 —— 这两件事在代码注释与 self-test 第 66 条里都锁住了。

## 9. 复核脚本（加新标的前先跑这个）

```python
import importlib.util
spec = importlib.util.spec_from_file_location("pa", "tools/push_auto.py")
pa = importlib.util.module_from_spec(spec); spec.loader.exec_module(pa)

codes = ["sh000300", "int_nikkei", "hf_NQ", "hkHSI", "bj430047"]   # 换成你要加的
code, raw = pa.http_request(pa.make_sina_url(pa.DEFAULT_SINA_URL, codes),
        headers={"User-Agent": pa.USER_AGENT, "Referer": pa.SINA_REFERER},
        encoding="gb18030", accept="*/*")
print("http=", code)
for line in raw.strip().splitlines():
    key = line.split("=")[0][len("var hq_str_"):]
    fields = line.split("=", 1)[1].strip().rstrip(";").strip('"').split(",")
    if len(fields) == 1 and not fields[0].strip():
        print("  %-14s EMPTY ← 无效代码" % key); continue
    print("  %-14s nf=%-3d %s" % (key, len(fields), fields[:6]))

rows, date = pa.fetch_quotes(pa.DEFAULT_SINA_URL, codes, 15, False)
print("解析:", rows)
print("行情日期:", date, "（只应来自 A 股行）")
```

或者直接用内置的（会额外打印开市判定与推送 payload）：

```bash
python3 tools/push_auto.py --stock-dry-run \
  --symbols sh000300,sz399303,int_nikkei,hf_NQ,hkHSI \
  --symbol-names CSI300,CNI2000,NIKKEI,NQ,HSI
```

## 10. 存疑 / 未实测

- `nf_*`（国内期货）逐下标含义**未实测**，只知道字段数 44~50 且 `f[30]` 不是日期
- `rt_*` 除 `rt_hkHSI` 外未逐一验证；本项目按前缀一律拒绝
- `hf_` 的 `f[1]`、`f[2]`、`f[3]`、`f[4]`、`f[5]`、`f[9..11]` 语义未逐一确认（本项目只用 `f[0]`/`f[7]`/`f[12]`/`f[13]`）
- `hk*` 的 `f[13]`/`f[14]` 恒为 `0.000`，语义未知
- `int_` 是否还有本项目未列举的代码（道琼斯/纳斯达克/标普/恒生/伦敦已验证）
- 成交量 `f[4]`（简版）单位：多家开源实现按「手」处理，成交额按「万元」，**本项目未实测**（盘中全 0），要用之前先在盘中验一次
